本文安排 MiniSQL 下一阶段的十二类功能扩展，沿用[现有三人分工](三人分工.md)中的“编译器—存储—执行引擎”责任边界。成员一、二、三可替换为真实姓名；不预设截止日期或个人工时。

**状态：成员一的扩展编译任务已实现并通过独立验收；执行、存储、持久化和端到端验收待接入。** 详见 [编译器报告](SQL扩展编译器报告.md)。现有单表增删改查、排序分页、事务及图形工作台作为基础保留。上一轮本地 619 项 Python 测试通过，仅作为历史基线；原文档编写时未重测；本次编译器扩展的实际重测结果另记于编译器报告。

已确认的首版边界：

- 继续使用现有 MiniSQL 引擎、Python 标准库和本地图形工作台。
- 索引采用 B+ 树，支持单列、联合及唯一索引。
- 视图仅支持普通只读视图，不实现物化视图或通过视图写入。
- 触发器采用 AFTER 行级触发，支持 OLD/NEW，禁止直接和间接递归触发。
- 权限采用管理员和用户直接授权，不实现角色继承。视图与触发器按调用者权限执行。
- 服务继续仅监听本机；高级并发、存储过程、公网部署和批量写入语法不纳入本次安排。
- 新类型必须接通编译、存储、执行和结果展示；NULL 是缺失值语义，不作为可声明的字段类型。

## 六、验收清单

### 查询与类型

- [ ] JOIN 覆盖同名字段歧义、自连接、一对多、空表、无匹配及外连接补 NULL。
- [ ] 聚合覆盖 COUNT(*) 与字段计数、空输入、NULL、重复值、分组与 HAVING，拒绝非法非分组字段。
- [ ] 条件覆盖 LIKE 通配符、否定形式、BETWEEN 边界以及 NULL 与 NOT IN。
- [ ] 子查询覆盖标量零行/一行/多行、FROM 别名、相关作用域和未知字段。
- [ ] 集合操作覆盖列数/类型不匹配、重复行、NULL 及结果排序分页。
- [ ] 新类型覆盖精度和范围边界、非法日期、BOOL/INT 区分、NULL、中文及真实文件往返。

### 结构、约束与索引

- [ ] ALTER 验证有数据表的增删字段、重命名、类型转换失败以及依赖对象保护。
- [ ] 约束验证存量数据、重复主键/唯一键、外键违规、NOT NULL、CHECK 和 DEFAULT。
- [ ] UPDATE 验证多行约束、旧值赋值语义及失败恢复，避免仅校验单行而遗漏最终数据冲突。
- [ ] 索引结果与全表扫描一致，覆盖联合前缀、等值/范围、重复键及 NULL。
- [ ] B+ 树覆盖节点分裂合并、根变化、跨页、回收、损坏输入和重新打开。
- [ ] 索引随 INSERT/UPDATE/DELETE 同步，失败、回滚和崩溃恢复后与数据一致。
- [ ] 索引性能对比注明数据量、选择性、缓存条件、实际耗时和统计口径，不伪造加速结论。

### 视图、触发器与权限

- [ ] 视图重启可查，支持嵌套，拒绝循环依赖与通过视图写入，保护底层对象变更。
- [ ] 多行操作的触发次数准确，OLD/NEW 值和多个动作顺序符合约定，直接/间接递归被拒绝。
- [ ] 触发失败时，原操作和派生写入共同恢复；显式事务沿用失败后必须回滚的规则。
- [ ] 错误密码、未登录访问和越权请求被拒绝；授权、撤权及密码修改符合会话规则。
- [ ] 多页面身份隔离，管理员保护生效；CLI、GUI、视图、子查询及触发器均不能绕过鉴权。
