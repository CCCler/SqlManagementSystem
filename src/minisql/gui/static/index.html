使用帮助
一个可观察、可交互的数据库系统原型。
课程实验

      

        
01 · 连接你的数据库
默认打开项目下的 data/gui。通过右上角「管理连接」输入其他本地目录；不存在的目录会被创建。每个页面拥有独立连接，修改目录前需提交或回滚事务。

        
02 · 编写与运行 SQL
点击「加载示例」可填入建表、插入和查询语句，示例不会自动运行。已有同名表时，再次建表会报错。SQL 以分号结尾，支持多条语句。Ctrl+Enter 运行选中内容，无选区时运行全部；Tab 插入两个空格。

        
支持 CREATE TABLE、INSERT、SELECT、DELETE、UPDATE、DROP TABLE、EXPLAIN SELECT 和事务语句。查询支持 WHERE、DISTINCT、ORDER BY、LIMIT/OFFSET；字段类型为 INT、VARCHAR，布尔常量可用于表达式。INSERT 必须列出全部列名。点击上边栏「浏览」可查看所有数据表，点击表名浏览其全部数据。UPDATE 支持多列赋值和整数加减，省略 WHERE 会更新全表；例如 UPDATE experiments SET score = score + 1 WHERE id = 1;。暂不支持 JOIN。

        
03 · 理解事务与错误
默认每条 SQL 自动提交。批次遇错停止后续执行，之前自动提交的语句仍可能已生效；失败批次不返回部分结果，可重新查询核实。显式事务发生错误后必须回滚，不能继续提交。

        
断开连接、关闭页面或关闭服务会尝试回滚未提交事务。页面异常离开时，最长 30 分钟空闲后释放连接；没有提交的事务不要长时间搁置。多个页面访问同一数据库时，未结束的事务可能使其他页面遇到锁超时。

        
04 · 观察编译与缓存
运行 SQL 后可切换到「编译分析」查看成功编译的语句。编译成功不代表执行或提交成功；失败阶段以执行结果中的错误为准。「缓存统计」显示引擎真实页缓存快照，目录刷新不替换最近执行的展示数据。

        
05 · 文件与显示
SQL 文件使用 UTF-8 编码，单次请求最多 256 KB。结果每页显示 50 行，显示分页不会重新查询。保存按钮将编辑器内容下载为 SQL 文件。工作台仅在本机运行，无需联网。
